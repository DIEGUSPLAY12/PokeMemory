# PokeMemory

Juego de memoria (Memory) con temática Pokémon desarrollado con HTML, CSS y JavaScript Vanilla (módulos ES) sobre Vite, interactuando con la PokeAPI.

## Cómo ejecutar el proyecto

1. Instalar las dependencias del proyecto:
```bash
npm install
```

2. Iniciar el servidor de desarrollo local:
```bash
npm run dev
```

3. Abrir en el navegador la URL proporcionada por Vite (habitualmente `http://localhost:5173`).
